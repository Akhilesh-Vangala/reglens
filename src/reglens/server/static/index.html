RegLens

A member-service copilot for credit-union staff, grounded in the federal consumer-banking regulations. The model proposes; deterministic code decides: every claim is a verbatim quote checked against the pinned regulation text, every date comes from a calculator, and anything unsupported goes to a person.

Citation graph
